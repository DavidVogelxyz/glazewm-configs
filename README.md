GlazeWM configs
===============

This repo manages both the GlazeWM and Zebar configs for a standard Windows 10/11 system.

Installation
------------

If it's not already installed, grab the `Microsoft Visual C++ 2015` package.

Then, install [GlazeWM](https://github.com/glzr-io/glazewm).

Clone this repo into the user's home directory. The name of the directory should be `.glzr`.
